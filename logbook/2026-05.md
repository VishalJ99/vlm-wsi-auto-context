### PER-207 Stage 5 Split/Reduce Marked Skipped

Decision:
Stage 5 split/reduce review is skipped as an active pipeline step. The prompt,
runner, and low/high thinking PDFs remain as experimental evidence, but this
stage should not be scaled across the pilot set for now.

Rationale:
The split/reduce question is fundamentally ill posed for the current detector
oracle. A bbox may contain overlap or another visible tissue-like instance, yet
still be practically acceptable if it focuses on one usable tissue candidate.
Deciding whether to split requires subjective reasoning about instance identity,
overlap, and downstream value. That likely needs larger-model reasoning, and
the return on investment is not there for this phase. The goal is a decent
high-recall tissue detector plus robust crop-level filtering, not perfect
atomic boxes.

- Do not run more Stage 5 split/reduce calls as part of the default pipeline.
