`latest` is currently unsafe with mixed run names.

Next steps:
- Add explicit `--run-id` or `--run-pattern` support to

  metadata `created_at`.
- Reuse existing Stage 1 bboxes whenever reviewing the same slide to avoid
  duplicate OpenRouter bbox calls.
- Consider lower PNG compression for reviewer crops/overlays, or a batch export
  CLI that amortizes Python import/startup across multiple slides.
